## 2. QUÉ ES
Log de control de acceso de 4 molinetes físicos ubicados TODOS en la
entrada principal de una universidad. Cada fila es una activación de
molinete (una "pasada"), no una persona. Sistema tipo ZKTeco/Hikvision.

## 3. COLUMNAS (13)
1.  Tiempo                  -> fecha y hora exacta de la activación del molinete.
                              Rango en este reporte: 2026-04-07 21:36:19
                              a 2026-04-24 11:08:41.
2.  Nombre de Área          -> constante = "Entrada". Todos los molinetes
                              están físicamente en la entrada principal.
                              No aporta para segmentar (valor único).
3.  Nombre de Dispositivo   -> el molinete, identificado por IP. 4 molinetes:
                              192.168.5.111, 192.168.5.110, 192.168.5.112,
                              192.168.5.106.
4.  Punto del Evento        -> indica ENTRADA o SALIDA y desde qué molinete.
                              El texto suele traer "Entrada"/"Salida", EXCEPTO
                              el molinete 5.106, que hay que mapear a mano:
                                192.168.5.106-2  = ENTRADA
                                192.168.5.106-1  = SALIDA
                              (los otros molinetes ya dicen Entrada/Salida en
                              el propio texto del punto).
5.  Descripción del Evento  -> tipo de evento. Valores y significado:
                                "Apertura con verificación normal" = usuario
                                    normal, acceso OK (77.242 filas).
                                "Usuario no registrado" = credencial sin
                                    persona válida asociada (15.004 filas).
                                    Estas filas tienen ID/Nombre NULOS.
                                "Deshabilitada" = ESTUDIANTE BLOQUEADO POR
                                    DEUDA DE PAGO (7.344 filas).
                                "Conectado con el servidor" (119)
                                "No se puede conectar con el servidor" (114)
                                "Desconectado" (112)
                                "Equipo Inicializado" (65)
6.  Nivel de Evento         -> Normal / Excepción / Alarma.
                                "Deshabilitada" (bloqueado por deuda) se
                                correlaciona con Nivel = "Excepción".
                                Normal=77.426, Excepción=22.348, Alarma=226.
7.  ID                      -> id de la persona. NULO en filas de "Usuario no
                              registrado" (15.274 filas con ID nulo en total).
8.  Nombre                  -> nombre de la persona (nulo si no registrado).
9.  Apellido                -> apellido de la persona.
10. Tarjeta                 -> número de tarjeta/credencial.
11. Nombre de Departamento  -> abreviatura de la CARRERA o rol (ver tabla).
12. Nombre de Lector        -> lector físico del molinete (más granular que
                              el dispositivo).
13. Modo de Verificación    -> "Solo Huella" (87.694), "Solo Tarjeta" (11.896),
                              "Otro" (410).

## 7. ADVERTENCIAS DE CALIDAD DE DATOS (leer antes de calcular)
- FILA vs PERSONA: cada fila es una pasada de molinete. Para "cuántos
  estudiantes ingresan" hay que contar ID únicos (nunique), NO filas.
  Para "flujo/afluencia de molinete" sí se cuentan filas.
- 15.274 filas con ID nulo y 15.334 con Nombre nulo = eventos "Usuario no
  registrado". No se pueden atribuir a una persona ni carrera. Excluirlos de
  cualquier conteo por persona/carrera.
- La columna "Nombre de Área" es constante ("Entrada") -> inútil para segmentar.
- Molinete 5.106 no dice Entrada/Salida en el texto: mapear -2=Entrada,
  -1=Salida (ver columna 4).
- Al leer, ID y Tarjeta vienen como float (ej. 4699.0). Convertir a int/str
  para mostrar.
